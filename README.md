# VIKASH — THE SERIES

A personalized Netflix-inspired portfolio using React, TypeScript, Vite, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

For production: `npm run build`.

## Pending assets

The user's portrait and resume PDF have not been provided. An abstract SVG placeholder is shown and the resume is presented as an HTML summary. To add a photo, update `profile.portrait` in `src/data/portfolio.ts` and replace the placeholder. To enable PDF download, place your PDF in `public/assets/` and update `profile.resumePdf`.
